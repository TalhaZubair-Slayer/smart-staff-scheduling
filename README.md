# Smart Staff Scheduling & Attendance Management System

A responsive web application designed to simplify staff planning, attendance monitoring, and workforce management for organizations. This project helps managers create schedules, track attendance, and maintain operational efficiency in a single dashboard.

## Overview

The Smart Staff Scheduling & Attendance Management System is built as a modern React application to support:

- Staff scheduling and shift planning
- Attendance tracking and monitoring
- Daily workforce visibility
- Leave and absence management
- Efficient management of employee availability
- Clean, user-friendly dashboard experience

## Features

- Smart shift scheduling for employees
- Attendance status tracking
- Quick overview of staff availability
- Employee-friendly scheduling workflow
- Responsive interface for desktop and tablet use
- Scalable foundation for future backend integration

## Getting Started

### Prerequisites

Make sure you have the following installed:

- Node.js (v18 or newer)
- npm

### Installation

1. Clone the repository
2. Open the project folder
3. Install dependencies:

```bash
npm install
```

### Run the application

```bash
npm run dev
```

Then open the local URL shown in the terminal, usually:

```bash
http://localhost:5173
```

## Available Scripts

```bash
npm run dev
npm run build
npm run preview
npm run lint
```

## Build for Production

```bash
npm run build
```
